# **App Name**: Fredega Pro Downloads

## Core Features:

- Product Listing: Display a list of products with their cover image and title on the main page.
- Product Detail Page: Open a new page with detailed information for each product, including the cover image, video demo (MP4 or YouTube link), and a download button.
- Download Links: Provide download links via Google Drive for each product.
- Responsiveness: Ensure the website is fully responsive and adapts to different screen sizes (mobile, tablet, PC).
- Related products: Based on user viewing history, the app uses a tool to determine similar products which may be of interest, and suggests them to the user

## Style Guidelines:

- Primary color: Vivid blue (#29ABE2) to represent creativity and digital media.
- Background color: Light blue (#E5F5F9), providing a clean and airy backdrop.
- Accent color: Energetic orange (#FF9933) for call-to-action buttons and highlights.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral, and readable design.
- Use modern and minimalistic icons to represent file types and actions (e.g., download, play video).
- Use a grid-based layout to display products in a clean, organized manner.
- Subtle transitions and animations to enhance user experience (e.g., on hover effects for products).
